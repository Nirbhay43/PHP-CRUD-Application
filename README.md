#  PHP CRUD Application

##  Description
This project is a simple CRUD (Create, Read, Update, Delete) application built using PHP and MySQL. It allows users to manage data efficiently and demonstrates basic backend development and database operations.



##  Features
- Add new records  
- View all records  
- Update existing records  
- Delete records  
- MySQL database integration  



##  Database Setup
1. Open phpMyAdmin  
2. Create a new database (e.g., `crud_db`)  
3. Import the provided `database.sql` file  



##  Installation

1. Clone the repository  
2. Move project to `htdocs` folder  
3. Start XAMPP (Apache & MySQL)  
4. Import `database.sql` in phpMyAdmin  
5. Open in browser:  
   http://localhost/php-crud-application  



##  Tech Stack
- PHP
